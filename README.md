# منصة انضباط · INDIBAT

منصة الحضور والسلوك لمدرسة رأس الخيمة الحلقة الثالثة بنين.

- **رابط المنصة:** https://khaledsamehai.github.io/indibat/
- **الدخول:** بالبريد الوزاري فقط (`@moe.sch.ae`) مع كود تحقق على البريد، ويوافق مسؤول النظام على كل حساب ويحدد صفته الوظيفية.
- **إعداد قاعدة البيانات:** ملف `indibat-setup.sql` يُشغَّل مرة واحدة في Supabase.
